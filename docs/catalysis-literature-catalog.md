# 催化文献目录与预览

文献目录与首页使用同一份 DOI 去重目录。每次 `npm run build` 前自动重建；单独更新可运行 `npm run build:catalysis-literature`。输入为正式反应数据库、候选/导航队列，以及 `data/curation/catalysis/literature-additions-v1.json`，输出为 `public/data/catalysis_v2/catalysis_literature_catalog_v1.json`。

## 收录与使用边界

- 正式反应来源保留原有逐字段核验规则；文献预览不改变比较和训练资格。
- 候选、导航及新增文献只增加发现与阅读入口，不自动写入正式反应表。
- 新增条目必须保留 DOI、原题名、期刊、年份、出版社链接、核对日期、概述依据及中英文概述。缺失数值不补写，MOF 前驱体与运行中活性相不混同。
- 概述为编写的简短介绍，不能标为原文摘要。摘要检索摘录与出版社全文阅读应分别记录；未核对全文许可不能视为允许训练。
- 搜索统一处理 DOI URL、大小写、Unicode 下标与标点；精确 DOI 优先，结果不再被前八条截断。
- 回归测试逐条验证全部输入 DOI 与题名能进入同一检索目录，并通过实际首页搜索框检查 DOI 可发现性。目录遗漏时测试失败。
